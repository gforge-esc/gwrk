# Getting Help with gwrk

Use GitHub Issues for reproducible defects and GitHub Discussions for beta feedback. Follow `SECURITY.md` for private vulnerability reports. Blocked: none.

## Where to Post

| Need | Destination |
|---|---|
| Report a reproducible bug | [New issue: Bug report](https://github.com/gforge-esc/gwrk/issues/new?template=bug_report.yml) |
| Request a concrete feature | [New issue: Feature request](https://github.com/gforge-esc/gwrk/issues/new?template=feature_request.yml) |
| Propose a plugin | [New issue: Plugin request](https://github.com/gforge-esc/gwrk/issues/new?template=plugin_request.yml) |
| Share beta experience reports | [Discussions: Beta feedback](https://github.com/gforge-esc/gwrk/discussions/categories/alpha-feedback) |
| Suggest an outcome or idea | [Discussions: Ideas](https://github.com/gforge-esc/gwrk/discussions/categories/ideas) |
| Show what you built | [Discussions: Show and Tell](https://github.com/gforge-esc/gwrk/discussions/categories/show-and-tell) |
| Ask a usage question | [Discussions: Q and A](https://github.com/gforge-esc/gwrk/discussions/categories/q-a) |
| Report a security vulnerability | Follow [SECURITY.md](SECURITY.md) privately |

## Before You Post

1. Search existing [issues](https://github.com/gforge-esc/gwrk/issues) and [discussions](https://github.com/gforge-esc/gwrk/discussions). Check the [public roadmap](https://github.com/orgs/gforge-esc/projects/5) too.
2. Include your `gwrk --version` and operating system. Also include your Node.js version and pnpm version. Name your agent CLI (`agy`, `claude` or `codex`).
3. Remove all tokens and cookies from logs before pasting output. Remove private key material as well.

## Response Expectations

A small team maintains gwrk during beta. Reproducible reports with exact command output and version metadata get reviewed fastest.

## Notes / Deferred

- **No deferred requirements.** Every US/FR/TR in the spec has ≥1 test case. All
  three phases' TRs were generated in one pass (the feature is a coordinated
  parser/generator/validator change across only three test files).
- **TR-008 scope (no silent cap)**: `000-tdd-infrastructure` (`## Phase` h2) and
  `021-polyglot-toolchain` (single `## Phases`) are explicitly excluded from the
  phase-count regression because they have never matched the `### Phase N: Title`
  heading the parser requires; the additive grammar does not touch phase-heading
  parsing. They are asserted to *still* throw `No phases found` so that invariant
  stays locked. The 15 `### Phase`-form specs are regression-locked by name.
- **Regression locks are green pre-implementation by design** (TR-004, TR-008,
  the bare-Type FR-003 case, and both non-fatal error-state cases): they pin
  existing behavior the change must preserve, so they must pass before *and*
  after. Every genuinely new-behavior assertion (FR-001/002/003 new grammar,
  FR-005 prompt, FR-006 validator) is RED.
- **VR-004** (`jq` over `specs/_fixtures/plan-format/.gwrk/tasks.json`) is a
  post-implementation verification step; its assertions are covered behaviorally
  by the FR-001/TR-007 SEAM tests (gate contains `make test:db`, no `^echo "Phase`).
